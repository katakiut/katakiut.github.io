# Créditos de imágenes de ejercicios

Los 173 movimientos de la aplicación usan pares de imágenes de demostración del repositorio público [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db), en particular los archivos `exercises/<id>/0.jpg` y `exercises/<id>/1.jpg`. El repositorio publica el conjunto bajo [Unlicense / dominio público](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md). La versión de `main` consultada fue actualizada el 27 de septiembre de 2026.

Para Memo Set, las dos poses originales se redimensionaron con proporción conservada a un ancho máximo de 512 px y se convirtieron a GIF animados en bucle con una paleta compartida de 128 colores. Los GIF se distribuyen localmente en `exercise-media/`, sin llamadas a una API ni marca de agua.

Los recursos fuente se enlazan por ID de ejercicio, por ejemplo: `https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/Barbell_Hip_Thrust/0.jpg`.
